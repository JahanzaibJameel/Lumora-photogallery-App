#### ...understand the codebase

1. Read [Architecture](./ARCHITECTURE.md)
2. Review [API Reference](./API_REFERENCE.md)
3. Explore [Testing](./TESTING.md)

#### ...add a feature

1. Check [Roadmap](./ROADMAP.md) for planned work
2. Review [Architecture](./ARCHITECTURE.md) for patterns
3. Follow [Contributing](./CONTRIBUTING.md) workflow
4. Add tests per [Testing](./TESTING.md)
5. Document in [Changelog](./CHANGELOG_GUIDE.md)

#### ...fix a bug

1. Check [Troubleshooting](./TROUBLESHOOTING.md)
2. Review [Architecture](./ARCHITECTURE.md) for context
3. Write test in [Testing](./TESTING.md) format
4. Follow [Contributing](./CONTRIBUTING.md) workflow

#### ...improve performance

1. Read [Performance](./PERFORMANCE.md) guide
2. Run [Bundle Size](./BUNDLE_SIZE.md) analysis
3. Check [Architecture](./ARCHITECTURE.md) for caching
4. Test with [Testing](./TESTING.md) utilities

#### ...update the design

1. Review [Design System](./DESIGN_SYSTEM.md)
2. Check [Accessibility](./ACCESSIBILITY.md) requirements
3. Follow [Contributing](./CONTRIBUTING.md) workflow
4. Update [Features](./FEATURES.md) if needed

#### ...deploy the app

1. Read [Deployment](./DEPLOYMENT.md)
2. Check [Bundle Size](./BUNDLE_SIZE.md)
3. Review [Security](../SECURITY.md) policy
4. Update [Changelog](../CHANGELOG.md)

#### ...run tests

1. Read [Testing](./TESTING.md)
2. Run `npm test`
3. Check [Troubleshooting](./TROUBLESHOOTING.md) if issues

#### ...set up locally

1. Follow [Quick Start](./QUICK_START.md)
2. Check [Troubleshooting](./TROUBLESHOOTING.md) if needed
3. Read [Contributing](./CONTRIBUTING.md) for workflow
